# Profils ICC

`FOGRA39L_coated.icc` — *Coated FOGRA39 (ISO 12647-2:2004)*, offset sur papier couché.
Généré par le projet [colord](https://github.com/hughsie/colord) à partir des données de caractérisation FOGRA39,
distribué sous licence **CC0-1.0** (paquet Debian/Ubuntu `colord-data`).

Utilisé par `server/utils/printPdf.ts` pour convertir les cartes en CMJN et comme *OutputIntent* des PDF imprimeur.
